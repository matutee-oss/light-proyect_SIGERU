## Dónde conseguirlas (bancos gratuitos y sin marca de agua)

- **Unsplash** — https://unsplash.com/s/photos/garbage-collection
- **Pexels** — https://www.pexels.com/es-es/buscar/recoleccion%20de%20basura/
- **Pixabay** — https://pixabay.com/es/images/search/basura/

Buscá términos como: "garbage truck", "waste collection", "recycling workers",
"street cleaning", "urban recycling". Descargá en JPG (más liviano que PNG
para fotos) y renombralas exactamente como en la tabla.

## Formato recomendado

- **JPG** para fotos (más liviano)
- Tamaño alrededor de 800×600 (horizontales) o 600×800 (verticales)
- Peso ideal: menos de 200 KB cada una

Si necesitás optimizarlas, https://squoosh.app te sirve para reducir peso sin
perder mucha calidad.
